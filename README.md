# План AI-курса: тарифы Lite / Pro / Business

Весь сайт — один файл `index.html`. Сервер и сборка не нужны.

## Как открыть

```bash
git clone https://github.com/evrytests-maker/ai-course-plan.git
```

Затем откройте `ai-course-plan/index.html` двойным щелчком — он запустится в браузере.

Без git: кнопка **Code → Download ZIP** на этой странице, распакуйте архив и откройте `index.html`.

Шрифты подгружаются из Google Fonts; без интернета страница работает, но со стандартными шрифтами.
